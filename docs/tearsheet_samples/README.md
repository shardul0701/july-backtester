# Tearsheet layout samples

Reference PDFs generated by `report.py` from the same source run
(`Nasdaq_100 / SMA_Crossover_20d_50d`, 1,819 trades, 2004–2026) so the two
layouts can be compared side by side.

| File | Layout | Pages | Command |
|---|---|---|---|
| `v3_tearsheet_sample.pdf` | **v3** (default) — dense 2-page institutional | 2 | `python report.py <csv>` |
| `classic_tearsheet_sample.pdf` | classic — full deep-dive | 14 | `python report.py <csv> --layout classic` |

Regenerate with:

```bash
python report.py <path/to/strategy.csv> --layout v3      --output-dir <dir> --report-name v3_tearsheet_sample
python report.py <path/to/strategy.csv> --layout classic --output-dir <dir> --report-name classic_tearsheet_sample
```
